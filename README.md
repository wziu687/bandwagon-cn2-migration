## 搬瓦工 CN2 机房切换步骤（KiwiVM 操作）

说实话，操作本身不复杂，四步就搞定。

1. **登录 KiwiVM 控制面板**：进搬瓦工官方后台 → Services → My Services → 找到你的 VPS → 点击「KiwiVM Control Panel」按钮。
2. **进入机房切换功能**：左侧菜单找到「Migrate to another DC」，点进去，你会看到当前所在机房的位置。
3. **选择目标机房**：下拉列表里选你想迁过去的 CN2 机房，点「Confirm on next step」进入下一步。
4. **确认并开始迁移**：确认界面直接点「Start Migration」，等待。

等多久？跟你 VPS 里的数据量有关。空机一两分钟就好，装了不少东西的可能要 10-15 分钟。迁移完成后会发邮件通知，邮件里有新机房的 IP 地址。

**切换机房会有什么变化？**

- IP 地址会换。切换到新机房，就是新 IP。
- 数据不会丢。搬瓦工切换机房只是换物理位置，VPS 里的数据全部保留。
- 如果你之前从 A 机房切到 B 机房，再切回 A 机房，IP 大概率会恢复成原来的（前提是没被别人用掉）。

有一点要注意：切换本身不需要流量，但迁移过程中搬瓦工会把迁移操作的数据计入本月总流量。通常量不大，影响不明显，但要是快到月末流量快用完了，最好稍微留意一下。

## 三大运营商分别选哪个 CN2 机房

这部分才是很多人真正搜这篇文章的原因：换了机房还是慢，问题可能出在没选对运营商对应的最优线路。

### 电信用户

优先 **DC6（USCA_6）或 DC9（USCA_9）**。这两个机房走电信 CN2 GIA（AS4809）全程，就是电信自己的高端国际骨干网，晚高峰抗拥堵能力比普通 163 骨干强很多。用下来的感受是，大多数时候峰值时段也基本不会掉到不能用的程度。

DC6 是经典机房，带宽最高能到 10Gbps；DC9 换用了 AMD EPYC 处理器加 NVMe 存储，硬件性能更新，线路质量和 DC6 是一个档次的。选哪个基本看当时哪个延迟更低，可以两个都试试。

### 移动用户

也是先试 **DC6 或 DC9**。搬瓦工在这两个机房接入了移动 CMIN2 精品线路（AS58807），移动用户走这个就是直连，不绕路。以前移动用户用搬瓦工一直被吐槽绕欧洲，CMIN2 接入之后这个问题基本解决了。

日本大阪软银（JPOS_1）也可以考虑，软银和中国移动之间有直连，延迟下限很低，但不是所有移动用户都能稳定跑满，要看运气。

### 联通用户

三个选择：DC6/DC9（走联通 CUP，AS9929 精品网）、日本大阪软银（JPOS_1，软银直连延迟低）、荷兰 EUNL_9（联通精品线路，欧洲业务方向）。

要在国内跑速度，先试软银。联通到日本软银的延迟通常比到美西低 30-40ms，体验差异挺明显的。

## 切换机房的几个常见问题

**Q：切换机房会不会影响续费价格？**

不会。机房切换完全免费，不影响套餐价格，也不影响续费周期。

**Q：切换完 IP 被封怎么办？**

IP 被封和机房切换是两回事。切换机房会拿到新 IP，但如果新 IP 也是被封的状态，还需要再换一次，或者在 KiwiVM 里付费换 IP（搬瓦工支持付费获取新 IP，不需要换机房）。有意思的是，如果你只是想换 IP 并不想换机房，也可以在 KiwiVM 里直接操作——切换机房换 IP 是免费的，单独换 IP 是付费的，所以很多人用切机房的方式来免费换 IP。

**Q：列表里有些机房显示 full 是什么意思？**

就是那个机房满了。常见于热门机房（比如 DC6）在补货或者节假日期间。等几个小时再试一般就好了，偶尔需要等一两天。如果出现 `Region is full. Please try again in a few hours. (734104)` 这类报错，不是账号有问题，是机房客满，耐心等就行。

**Q：CN2 GIA-E 套餐和 DC9 CN2 GIA 限量版有啥区别？**

CN2 GIA-E 是常规套餐，长期有售；DC9 CN2 GIA 限量版是不定时补货的限量版，价格更低但只能锁定在 DC9 一个机房，不支持迁移到其他机房。如果你需要随时切换机房的灵活性，选常规 CN2 GIA-E。如果只用 DC9 一个机房且价格是第一优先级，可以等限量版补货。

**Q：我刚买的是 KVM 套餐，能升级到 CN2 GIA-E 吗？**

目前搬瓦工不支持直接升级套餐。只能重新购买 CN2 GIA-E 套餐，然后在新 VPS 里重新部署。如果之前的 KVM 套餐还在有效期内，可以申请退款（30 天内不满意可以全额退），用退款补差价买 CN2 GIA-E。
